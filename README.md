# Retail Product Demand Prediction Using Machine Learning

## Overview

This project focuses on predicting retail product demand using machine learning techniques. Accurate demand forecasting helps retailers optimize inventory, reduce stock shortages and overstocking, and improve overall supply chain efficiency.

The project involves data preprocessing, exploratory data analysis (EDA), feature engineering, model training, and performance evaluation. Multiple machine learning models were trained and compared to identify the best-performing model while analyzing training and testing results to detect overfitting and underfitting.

## Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering and selection
* Training multiple machine learning models
* Model evaluation using performance metrics
* Comparison of training and testing performance
* Selection of the optimal model for demand prediction

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## Machine Learning Workflow

1. Load and preprocess the retail dataset.
2. Handle missing values and encode categorical features.
3. Perform exploratory data analysis to understand sales patterns.
4. Split the dataset into training and testing sets.
5. Train multiple machine learning models.
6. Evaluate model performance using metrics such as RMSE, MAE, and R² Score.
7. Compare models to identify overfitting or underfitting.
8. Select the best-performing model for retail demand prediction.

## Results

The trained models were evaluated on both training and testing datasets to ensure good generalization. By comparing model performance, the project identifies the most suitable model for accurate retail product demand forecasting while minimizing overfitting and underfitting.
